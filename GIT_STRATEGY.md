# Git Strategy

## Rules
- No destructive git commands without explicit approval.
- Every builder, package, and module must be committed immediately.
- Every phase must be reproducible.
- Git Commits and Git Tags are strictly required at the completion of each phase.

## Workflow per Phase
1. Implementation Plan
2. Approval
3. Execution
4. Walkthrough
5. Approval
6. Git Commit
7. Git Tag
